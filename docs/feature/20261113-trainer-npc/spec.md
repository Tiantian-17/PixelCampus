## 1. 背景与目标

承接 #5–#6。当前只有野生精灵和校园猫友谊赛；野外 3–9 级，10 级以后内容空。本批补：

- 训练家 NPC：固定队伍、战前 / 战后台词、首次奖励、可重复挑战。
- `Battle` 从「我方队伍 vs 单只野生精灵」扩展成「我方队伍 vs 对方队伍」。
- 一个 10–20 级区域，补上等级空档。

## 2. 三个训练家

| id | 名字 | 位置 | 等级 | 队伍 | 战前台词 | 奖励 |
|---|---|---|---|---|---|---|
| t1 | 图书馆学长 | 图书馆正门前台阶旁 | 8–10 | 2 只（一般 / 超能力） | 「来切磋一下？」 | 300 币 |
| t2 | 操场体育生 | 东操场看台边 | 14–16 | 3 只（格斗 / 岩石 / 飞行） | 「热身完了？那就来一场！」 | 500 币 + 5 零食包 |
| t3 | 湖畔钓客 | 精工湖南岸 | 20–22 | 3 只（水 / 冰 / 毒） | 「钓鱼不如钓对手，来不来？」 | 800 币 + 1 碳素鱼竿 |

- 战败台词、再次挑战台词各一句。
- 常驻固定位置，不游走；战后冷却 30 秒。

## 3. 战斗结构改动

- `Battle` 增加 `foeSquad: Mon[]`、`foeLead: number`；单只野生精灵仍是 `foeSquad` 长度为 1 的特例。
- `mon_bt` 的 `foe` 增加 `squad`（对方队伍的血量 / 等级 / 物种）和训练家信息 `trainer: { id, name, sprite }`。
- 对方精灵倒下 → 服务器换人 → 推 `mon_bt`（带新上场精灵）。
- 我方 / 对方换人走同一套 `swap` 事件。

## 4. AI

纯函数放 `src/shared/trainer-ai.ts`：

- 出招：60% 概率从「对当前对手克制（倍率 ≥ 2）」的招里选，否则随机。
- 换人：当前精灵血量 < 25% 且队里还有活的、且连续 2 回合没换过 → 30% 换人。
- 确定性：用注入的 `Rng`，相同种子结果一致。

## 5. 协议

C→S：

- `trainer_battle { id: string }`：请求切磋
- `trainer_info { }`：请求训练家进度（可选，进图时由 `mon_data` 带）

S→C：

- `trainer_data { beaten: number[] }`
- `mon_bt` 扩展：`foe.squad`、`trainer`
- `trainer_result { id, ok, msg, reward? }`

## 8. 正向场景

- **P1.** 靠近训练家按 E，弹出对话，可选「切磋」或「下次吧」。
- **P2.** 选「切磋」后进入战斗，对方有多只精灵，界面显示训练家名字和对方队伍。
- **P3.** 对方精灵倒下后，服务器换人，日志写「XX 派出了 YY」，战斗继续。
- **P4.** 我方全灭 → 回半血、回校门口，训练家状态不变。
- **P5.** 打赢 → 战后台词 + 首次奖励（币 / 道具），`trainers` 记 id。
- **P6.** 再次挑战 → 可打，无奖励，战后台词不同。
- **P7.** 逃跑 → 结束战斗，无奖励，可再挑战。
- **P8.** 战斗后 30 秒内不能再次切磋。
- **P9.** `hill-deep` 区域按 10–20 级出没，青鳞稀有。
- **P10.** AI 会选克制招、会在低血量换人。

## 9. 反向 / 异常场景

- **N1.** 训练家 id 不存在 / 非法时**绝不能**崩溃，返回错误提示。
- **N2.** 冷却中再次请求**绝不能**开战。
- **N3.** 旧存档没有 `trainers` 字段**绝不能**读取失败。
- **N4.** 对方队伍里有倒下的精灵**绝不能**再被派上场。
- **N5.** 训练家战斗**绝不能**和野生战斗会话混用（同一时间只能有一场）。
- **N6.** 奖励**绝不能**重复发放（同一 id 只发一次）。
- **N7.** `hill-deep` 和 `hill` **绝不能**重叠。
- **N8.** 客户端**绝不能**自行决定战斗结果或奖励。
- **N9.** 玩家可见文字**绝不能**用 `innerHTML`。
